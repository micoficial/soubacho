# まちの相場帳

土地・中古マンション・戸建てが「実際にいくらで売れたか」を、国土交通省が公表している取引価格から市区町村・駅・町（地区）ごとに集計して、無料で見せる静的サイトです。

公開先：https://micoficial.github.io/soubacho/

## データ

| データ | 提供 | 使い方 |
|---|---|---|
| [不動産情報ライブラリ](https://www.reinfolib.mlit.go.jp/) 不動産価格（取引価格・成約価格）情報のダウンロード（全都道府県・すべての種類・2005年第3四半期〜最新、都道府県ごとの CSV、Shift_JIS） | 国土交通省 | 本体（約659万件） |

- 「不動産取引価格情報」（取引した人へのアンケート、2005年〜）と「成約価格情報」（レインズの成約価格、2021年〜）の2種類が入っている
- 公共データ利用規約（第1.0版）。商用利用可。出典「国土交通省 不動産情報ライブラリ」と、加工したこと（「不動産取引価格情報」（国土交通省）をもとに合同会社micoが作成）を書く。国が作ったように見せない。リンクはトップページへ。サービス名に「不動産情報ライブラリ」を使わない
- 国は四半期ごとにデータを追加する（1・4・7・10月ごろ）

## 動かし方

```bash
bash scripts/fetch.sh      # data/raw/All_*.zip（無ければリリース data-latest の控え）を data/raw/torihiki/ に展開
node scripts/build.mjs     # dist/ に約3.6万ページを生成（1分半ほど）
node scripts/serve.mjs     # http://localhost:4175/soubacho/ で確認
```

`LIMIT=200 node scripts/build.mjs` で地区・駅のページを200件ずつだけ作れる（試すとき用）。

## データの更新

- 国のサイトのダウンロードは画面の操作が要る（画面の裏の API を直接使うのは利用規約 第6条に触れるので使わない。公式 API はキーの申請が要るうえ、説明書の出力項目に最寄駅が無い）
- そこで、このPCの Edge を画面なしで動かして、人が押すのと同じ操作でダウンロードする：`node scripts/download-reinfolib.mjs --current 20261`（新しい四半期が無ければ `no-new-data`）
- 取った ZIP はリリース `data-latest` に置き、GitHub Actions はそれでサイトを作る：`GH_TOKEN=... bash scripts/refresh-data.sh data/raw/All_20053_20262.zip`
- このPCのタスク スケジューラ（`mico-soubacho-data-refresh`）が毎週月曜10時に `scripts/scheduled-refresh.sh` を実行し、新しい四半期が出ていれば上の2つを続けて行う。記録は `data/refresh.log`
- 手で取るとき：国のサイトの「不動産価格（取引価格・成約価格）情報の検索・ダウンロード」で、全都道府県・すべて・2005年第3四半期〜最新を選んでダウンロード → `refresh-data.sh` に渡す

## 仕組み

- `scripts/lib/load.mjs`：CSV を読んで列ごとの配列にする（659万行で20秒ほど）。列の並びが変わったら止まる
- `scripts/lib/stats.mjs`：集計の条件（土地＝住宅地30〜1,000㎡、マンション＝住宅用30〜200㎡、戸建て＝住宅用の土地と建物）、中央値、期間の選び方（直近2年→5年→10年）、5年前比（築年数・地区ごとに比べる）
- `scripts/pages/`：市区町村（`city.mjs`）、地区（`district.mjs`）、駅（`station.mjs`）、都道府県（`pref.mjs`）、ランキング（`ranking.mjs`）、トップ・説明・検索（`misc.mjs`）、共通の部品（`common.mjs`）
- `.github/workflows/deploy.yml`：push・毎週月曜3時30分・`refresh-data.sh` からの起動で作り直して GitHub Pages に出す。`data/summary.json` を毎回コミットするので定期実行が60日で止まらない

## 注意

- 金額は中央値。広さ・築年数・立地の組み合わせで動く。件数の少ない地域は期間を広げ、5件未満は出さない（個々の取引が分かるのを避ける）
- 取引の事情等（競売・関係者間・隣地・私道を含む など）がある取引は除く
- 取引価格情報と成約価格情報は水準が違う（成約の方が1〜2割低い地域が多い）ので、推移の線は分けている
- 値上がり率は、取引された物件の組み合わせで跳ねないよう、マンションは築年数の区分ごと、土地は地区ごとに比べた変化率の（件数で重みをつけた）中央値
